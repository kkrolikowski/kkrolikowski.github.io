# Quickstart: CV Website Redesign Preview

**Feature**: CV Website Redesign
**Date**: 2026-05-13

## Environment
This is a static HTML project. No compilation or server-side environment is required.

## Local Preview
1. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
2. Alternatively, use a local development server for better control (e.g., VS Code "Live Server" extension or `python3 -m http.server`).

## Development
- **Styling**: All custom styles are in `style.css`.
- **Interactivity**: Theme toggle and scroll logic are in `script.js`.
- **Components**: UIkit components are loaded via CDN in `index.html`.

## Validation
To verify the redesign:
1. **Responsiveness**: Use Browser DevTools (F12) to toggle device emulation and check mobile/tablet layouts.
2. **Performance**: Run a Lighthouse audit from the Chrome DevTools "Lighthouse" tab.
3. **Accessibility**: Use the "axe DevTools" or "WAVE" browser extension.
