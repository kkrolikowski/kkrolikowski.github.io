# Quickstart: Visual Polish & UX Fixes

## Verification Steps

### 1. Theme Toggle Icon Swap
- Open the website.
- Click the theme toggle button.
- **Verify**: The icon changes from a Moon (when light mode is active) to a Sun (when dark mode is active).
- **Verify**: The theme colors switch correctly as per the design tokens.

### 2. Hero Section Alignment
- Inspect the Hero section on a desktop screen.
- **Verify**: The top of the author image container is visually aligned with the top of the "Krzysztof Królikowski" text.
- **Verify**: The space below the image is occupied by decorative pseudo-elements.

### 3. ScrollSpy Navigation
- Scroll through the page from top to bottom.
- **Verify**: The active section in the top navigation menu is highlighted with a green color (or the current primary color).
- **Verify**: The highlighting changes automatically as new sections reach the viewport.

### 4. Career Timeline Enrichment
- Navigate to the "Professional Career" section.
- **Verify**: The laptop image is no longer "tiny" and is integrated into the layout.
- **Verify**: Each experience card contains a "Team" or "Department" designation.

### 5. Border Radius Consistency
- Inspect the Hero buttons ("View Experience", "Technical Skills").
- **Verify**: Their corners have the same 20px curvature as the author's photo and the timeline cards.
